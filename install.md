# Installation Guide

To run or replicate the molecular docking pipeline in this repository, you will need to install **PyRx** (which includes AutoDock Vina).

## 📥 Official Download
You can download the latest version of the software from the official source:
* **[PyRx SourceForge Download Page](https://sourceforge.net/projects/pyrx/)**

## 💻 System Requirements & Setup
1. Download the appropriate binary installer for your operating system (Windows, Linux, or macOS).
2. Follow the standard installation wizard prompts for your platform.
3. Once installed, you can use the built-in Vina Wizard to load your receptor (`.pdbqt`) and ligand files as outlined in the main [README.md](README.md).
